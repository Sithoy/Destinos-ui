# Landing Module

The Landing module is the public DPM client entry point.

## Responsibility

- Present the Destinos pelo Mundo brand.
- Explain leisure, luxury, and corporate travel services.
- Capture simplified trip requests.
- Keep the client-facing request form short and low-friction.
- Route captured demand into the CRM for briefing and qualification.

## Current Implementation

Landing code currently lives in the existing `src/` application structure. Future cleanup should move landing pages, sections, translations, and inquiry components here in small steps.

## Key Flows

- Client explores DPM services.
- Client submits a simple travel planning request.
- DPM staff complete the internal CRM briefing before Trip Design.
